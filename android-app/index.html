FIRST TIME SETUP

Start the office engine in Termux

  1. Install Termux from F-Droid (Play Store version is outdated).
  2. Install the real OpenCode CLI in Termux and keep its glibc packages available.
  3. Tap Open Termux, then paste the commands below and press enter.
  4. Come back here and tap Re-check server.
pkg install python nodejs-lts -y
python3 -m pip install websockets==17.0.1
git clone https://github.com/omxrex/ai-office-android.git ~/ai-office-android
cd ~/ai-office-android
(cd app/provider-layer && npm ci --omit=dev --no-audit --no-fund)
sh scripts/start-android.sh

The office runs locally at 127.0.0.1:8090. Nothing is uploaded. Your chats, tasks and credentials stay on this device.
